# Photosへの写真の追加

1. Vercelのblogプロジェクト → Storage → blog-photos → Manage Blobsを開く。
2. `photos` フォルダを開く（なければCreate Folderで作成）。
3. UploadからPCの写真を複数選択してアップロードする。
4. `/photos` に自動反映される。キャッシュの更新は最短5分、更新後の次のアクセスで反映されるため、必要ならもう一度読み込む。再デプロイやNotionの編集は不要。

JPEG、PNG、WebP、AVIF、GIFに対応。HEICやRAWはJPEGに書き出してからアップロードする。閲覧用には長辺2,000〜3,000px程度の画像を推奨。

`photos/` 以下の画像はサブフォルダも含めて公開される。それ以外のファイルは表示されない。表示順はアップロード日時の新しい順、タイトルは拡張子を除いたファイル名（`_`と`-`はスペースに置換）。画像をクリックすると原寸画像を別タブで開く。公開したくない位置情報等はアップロード前に削除する。

ストレージ自体はPrivate。サイトの画像APIが`photos/`以下の対応画像だけを公開し、書き込みや削除はVercelのログイン済み管理画面だけで行う。アプリは接続時に設定される`BLOB_STORE_ID`とVercelの短期OIDC認証を使用するため、長期トークンの設定は不要。ローカルでストレージ設定がない場合は空のギャラリーになる。

Hobbyプランの無料枠はストレージ1GB、転送10GB/月、Advanced Operations 2,000回/月など。超過時は追加課金されず利用が停止する。写真の一覧取得はページの再生成時だけ行う。画像を大量に追加する際は閲覧用に縮小しておくと容量を節約できる。

## Tumblrからの移行

2026年10月26日に `https://daisukesone.tumblr.com/` の公開済み73投稿・110枚を移行。複数枚セット16投稿の53枚も含む。画像は公開ページに掲載されている最大サイズのURLから取得したもの（新しい投稿は最大2,048px、従来形式は主に1,280px）で、カメラの元データではない。合計53,373,409バイト、画像のSHA-256重複なし。

保存先は `photos/tumblr/<Tumblr投稿ID>-<投稿内の連番>.<拡張子>`。`data/tumblr-photos.json` が元の投稿日、投稿URL、取得元画像URL、投稿内の順番を保持する。投稿日はTumblr標準投稿ページの`parsely-pub-date`から全73投稿分を確認した。表示順はその投稿日を使用し、今後追加する通常の写真はアップロード日時を使用する。Tumblr側の投稿や写真は変更していない。

写真データはGitへ入れず、Vercel Blobに保存する。公開ページからの一度限りの移行なので、Tumblrの今後の更新は自動同期されない。
